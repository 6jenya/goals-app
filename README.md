# Мої цілі

Telegram Mini App для бота @zhenya_goals_bot: цілі, звички, монети, нагороди, штрафи й мрії.

- Вежа в нічному місті: кожен день із ділом — світлий поверх, день у нікуди — темний.
- Штрафи за шкідливе й за дні без жодної дії, вихідні без штрафу.
- Скарбнички, облік доходу з розподілом, відлік до 18, досягнення, рівні й теми неба.
- Дані зберігаються в CloudStorage Telegram; дані першої версії переносяться автоматично.

Збірка: `python3 build.py` у робочій теці складає `index.html` з `src/`.
